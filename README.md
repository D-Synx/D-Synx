# D.Synx

Informaticien, je développe des outils pour Windows et des projets en C++ et PHP.

## Projets

- **[DelProfils](https://github.com/D-Synx/DelProfils)** — outil en C++20 pour gérer les profils utilisateurs Windows, avec une attention particulière à la sécurité et aux cas limites.
- **[Sublime](https://github.com/D-Synx/Sublime)** — bibliothèque PHP légère pour générer du HTML de manière fonctionnelle et immutable.
- **[PagOS](https://github.com/D-Synx/PagOS)** — proposition d’architecture en recherche ; elle n’a pas encore été validée par des essais empiriques.
